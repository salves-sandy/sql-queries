##  Sobre este repositório

Este repositório contém uma coleção de projetos práticos e consultas SQL desenvolvidos para simular cenários reais do mercado de tecnologia e atendimento ao cliente. 

O objetivo é aplicar a inteligência de dados na tomada de decisões estratégicas de **Customer Experience**, cobrindo tópicos como:
* Mapeamento e prevenção de **Churn** (cancelamento de clientes).
* Análise de métricas de atendimento (**CSAT, NPS, SLA**).
* Identificação de gargalos operacionais e otimização de consultas (*query performance*).
* Segmentação de bases de dados e higienização/limpeza de registros.

##  Habilidades Demonstradas

- **Consultas Avançadas:** Joins múltiplos, agrupamentos e funções agregadas.
- **Lógica de Negócio:** Tradução de necessidades da equipe de CX em filtros e métricas no banco de dados.
- **Janelas & Subconsultas:** Uso de CTEs (*Common Table Expressions*) e Window Functions para análises estatísticas.
- **Tratamento de Dados:** Higienização de strings, gerenciamento de nulos e prevenção de duplicidades.
